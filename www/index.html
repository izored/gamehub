                While you play

                Controllers

                DualSense, DualShock 4 (also through DS4Windows) and Xbox controllers work in Game Hub: D-pad to move, Cross / A to play, Circle / B to go back, Triangle / Y for Favorites, Square / X to edit, L1 / R1 to switch tabs, Share / View to search.

                Controller not working in a Steam game?

                Steam decides how each game sees your controller, and Steam Input can be switched off for a single game. In Steam, open the game's controller settings (Library > right-click the game > Properties > Controller, or the controller icon while it runs) and turn Steam Input on for that game. If you use DS4Windows instead, leave Steam Input off for that game so it doesn't see two controllers.

                DS4Windows: per-game rules

                Choose what DS4Windows does while each game runs. "Turn off" lets the game or Steam Input see your real PlayStation controller; DS4Windows comes back when you leave the game. Game Hub writes the rules into DS4Windows and restarts it.
